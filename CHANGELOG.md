# Changelog

## 1.0.0 — 2026-09-16

First executable Research Local release based on FCEA-2026-V1.0-CORE by Vadym Tsinderhoz. Adds immutable evidence storage, typed contracts, four graph projections, scope/time checks, G0–G15, eight domain adapters and ten synthetic scenarios, numerical reproduction and proof packets, authenticated API/dashboard/CLI, review/release workflows, backups, container packaging, CI, source documentation and traceability.

The institutional/cloud deployment profiles and external scientific validation are outside this release. See [architecture boundaries](docs/ARCHITECTURE.md).
